# ADR-0001: 블록체인 클라이언트로 Hyperledger Besu 채택

- 상태: 승인
- 날짜: 2026-11-07

## 배경
초기 기획서는 컨소시엄 블록체인으로 GoQuorum을 사용하도록 되어 있었다.
그러나 GoQuorum은 2022년 Consensys가 지원 중단(deprecated)을 발표했고, 현재 저장소는 보관(archived) 상태로 유지보수되지 않는다.

## 결정
같은 이더리움 계열 클라이언트인 Hyperledger Besu를 사용한다.
- 합의 알고리즘: QBFT
- 가스비: 0 (zero base fee, min-gas-price 0)

## 근거
- 지속적으로 관리되는 프로젝트라 보안 패치를 받을 수 있다
- Solidity 스마트 컨트랙트, MetaMask 연결 등 기획서의 구조를 그대로 유지할 수 있다
- 지원이 끝난 소프트웨어는 알려진 취약점이 패치되지 않으므로, 보안 실험 프로젝트에서 사용하기에 부적절하다

## 결과
- 기획서의 GoQuorum 관련 설정은 Besu 기준으로 대체한다
- 1단계에서는 검증 노드 2개로 시작하고, 노드 수에 따른 가용성 문제는 보안 실험 S-06에서 다룬다
